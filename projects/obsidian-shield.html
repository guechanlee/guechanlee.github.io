01

내가 구현한 기능 — 회원 서비스

모든 계정은 마스터 계정에서 권한을 위임받는 구조이고, 권한이 없는 메뉴는 아예 보이지 않습니다. 그 바탕이 되는 가입·승인·로그인·권한을 만들었습니다.

01회원가입 · 입력 검증

잘못된 값이 DB에 들어가지 않도록 가입 단계에서 하나씩 막았습니다.

  • 아이디 중복 확인 후 수정 불가
  • 비밀번호 8자 이상 · 특수문자 포함
  • 이메일은 허용한 도메인만 가입 가능
  • 전화번호는 숫자만 3칸 입력, 하이픈은 저장 전에 제거
  • 입력값 전체 공백 제거

02계정 상태 · 승인 흐름

가입 직후에는 미승인 상태이고, 미승인 계정으로 로그인하면 "승인 대기 중" 화면 외에는 아무것도 볼 수 없습니다. 상급 계정이 승인해야 관제 메뉴가 열립니다.

03로그인 보안

  • ID·PW 공백 검사
  • 자동 입력 방지(Captcha)
  • 연속 로그인 실패 시 계정 자동 비활성화

04권한 구조 — 마스터 → 관리자 → 팀장 → 팀원

권한 트리로 설계했습니다. 가입 때 선택한 역할에 따라 권한 목록을 만들고(make_member()), 권한을 추가할 때 중복을 막습니다(apply_permissions()).

  • 권한 부여·회수는 상위 계정만 가능
  • 정보 수정은 상급 계정에 요청해 승인받는 방식
  • 삭제된 ID도 기록해 재사용을 막는 설계
02

팀 전체 기능

실시간 영상 관제

바운딩 박스가 그려진 실시간 영상, 탐지 예외 처리.

탐지 대상 관리

사진 몇 장으로 대상을 등록하면 학습 없이 바로 반영.

이벤트 · 알림

탐지 사유·시각·위치를 이벤트 로그로 쌓고 읽음 처리.

미니맵 · 이동 경로

탐지된 인원의 위치와 동선을 지도에 표시.

로그 · 내보내기

이벤트·사용자 활동 로그 조회, xlsx·json 내보내기.

03

AI 모델 구성

모델역할프로젝트에 맞게 조정한 점
YOLO영상 속 사람만 탐지, 위치 좌표·영역 추출classes=[0]으로 사람만 탐지, conf 0.4 · iou 0.55 · imgsz 640, 사전 학습 가중치 사용
BoT-SORT탐지된 사람에게 Track ID를 부여해 이동을 지속 추적카메라별 추적기 분리, 얼굴 인식 단계와 연결
InsightFace등록된 대상자 얼굴과 실시간 얼굴 비교 식별식별 임계값 0.45, 등록 얼굴 특징 벡터를 평균 저장, 비동기 처리
04

문제 해결

정확도 같은 수치 지표는 따로 측정하지 않았고, 사전 학습 모델을 그대로 쓰되 실제 영상에서 드러난 문제를 하나씩 찾아 대응한 과정을 기록했습니다.

문제원인해결 방안
사람 탐지 누락원거리 촬영·사람 가림 상황에서 YOLO가 놓칠 수 있음탐지 신뢰도·입력 크기 조정, 카메라 해상도·각도 개선, BoT-SORT 추적 정보 활용
Track ID 변경겹침·재등장 시 동일 인물의 Track ID가 바뀜카메라별 추적기 분리, Track ID별 결과 임시 저장, InsightFace로 재확인
얼굴 인식 환경측면·작은 얼굴, 어두운 환경, 마스크·안경에서 성능 저하여러 각도 사진 등록, 특징 벡터 평균 저장, 유사도 기준 적용, 일정 시간 후 재인식
실시간 처리 지연탐지·추적·얼굴 인식을 동시에 수행하면 영상 지연얼굴 인식 비동기 처리, 식별된 사람은 인식 주기 증가, 중복 분석 감소, 로그 저장 간격 설정
