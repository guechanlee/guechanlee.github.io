01

내가 구현한 기능

관리자가 구역과 캠을 등록하면 분석이 시작되고, 그 결과가 지도와 영상 화면으로 이어지도록 만들었습니다. 이미지를 누르면 크게 볼 수 있습니다.

01구역 관리 — 지도에서 그려서 등록

지도 위에 다각형을 그려 구역을 등록하면 면적과 소속 행정동이 자동으로 계산됩니다.

  • 면적(㎡)·소속 동 자동 계산 — JTS 기하 연산
  • 다각형 수정은 같은 동 안에서만 허용
  • 동서남북 이웃 구역을 지정하면 반대쪽에도 자동 반영

02캠 관리 — 구역당 1대, 상태에 따른 수정 제한

캠을 구역에 연결하고 입력 방식과 가동 상태를 관리합니다.

  • 구역당 캠 1대 규칙 검증
  • 더미 영상·라이브 입력 방식 선택
  • 가동·정지 제어, 정지 상태에서만 수정 가능

03실시간 보기 · 다시보기

탐지 박스가 그려진 라이브 영상을 보고, 통계에서 문제 시각으로 바로 이동해 녹화를 확인합니다.

  • 통계 그래프의 한 점이나 이벤트에서 그 시각의 녹화로 바로 이동
  • 탐지 박스 켜고 끄기, 현재 인원·밀집도·혼잡 단계 표시
  • 녹화 30일 보관

04대시보드 지도 · 캠 카드 미리보기

지도에서 구역별 혼잡 단계를 색으로 보고, 누르면 인원·밀집도 팝업이 열립니다.

  • Leaflet + OpenStreetMap 지도에 구역 핀과 혼잡 단계 색
  • 정상 · 주의(0.7명/㎡) · 위험(1.5명/㎡) 3단계
  • 캠 카드 최대 16장을 연속 영상 대신 2초마다 정지 화면으로 갱신
02

팀 전체 기능

팀이 함께 만든 통계·이벤트 기능입니다. 사용자 앱과 관리자 앱이 같은 데이터를 보도록 공통 모듈로 나눴습니다.

통계 · 엑셀

시간·일·주·월 통계 그래프와 구역별 현재 인원, 방문 패턴, 유입·유출 추정, 엑셀 내려받기.

이벤트 판정·처리

혼잡 단계 변화와 인원 급증을 이벤트로 판정하고, 관리자가 확인·처리하도록 기록.

계정·권한

가입·승인 대기·탈퇴, 관리자 계정, 작업 기록 조회(최고 관리자 전용).

분석 서버 연동

Flask 분석 서버가 1초 결과를 보내고, 관리자 앱이 1분·시간·일 단위로 집계.

03

문제 해결

문제원인해결결과
캠 카드 16장을 띄우면 다른 요청이 막힘카드마다 끊기지 않는 영상(MJPEG) 연결을 열어 브라우저의 도메인당 동시 연결 수 제한에 걸림최신 프레임 JPEG를 2초마다 받고, 보이는 카드만·탭이 숨겨지면 멈춤. 누르면 실시간 창인증서·분석 서버 부하 변경 없이 해결
캠을 가동해도 "현재 인원"이 한참 안 바뀜1분 통계가 저장될 때까지 값이 없음현재 인원은 메모리 누적기에서 5초마다 읽고, 15초가 지나면 쓰지 않음최대 70초 지연 해소
JTS 면적 계산 코드가 컴파일되지 않음 (Polygon.copy())JTS 1.20의 copy()가 Polygon이 아니라 상위 타입 Geometry를 반환변수 타입을 Geometry로 선언하고, 좌표 변환은 CoordinateSequenceFilter로 처리"copy()·buffer()는 Geometry 반환"이라고 가정하는 규칙을 문서화
동 경계 JSON을 읽으려는데 GeoJsonReader를 찾을 수 없음해당 클래스가 jts-core가 아니라 별도 라이브러리 jts-io-common에 있음의존성을 늘리지 않고 기존 RegionGeoJsonParser에 readGeometry()를 추가해 재사용JTS 클래스는 쓰기 전에 어느 모듈에 있는지 확인하도록 기록
